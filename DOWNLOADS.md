# FitLog M0 preview downloads

This branch distributes the existing ARM64 APK and its ZIP container only.
The app is an initial UI scaffold, NOT the completed workout tracker.
The APK embeds JavaScript/assets and does not require Expo Go or Metro.
It is signed with the default Android Debug certificate for preview use only.
Minimum Android API: 24. No physical-device test has been performed.
APK signature v2 and ZIP integrity were verified. The ZIP contains the identical APK.
The app was NOT rebuilt for this upload.

Built from local source snapshot 647a3dd; that source snapshot is not on main.
This download branch does not represent the source code of the APK.

Install: download the APK on an ARM64 Android phone, open it, and allow installation
from the app opening the file when Android prompts you. This preview does not yet
record workouts or implement the remaining product milestones.

See SHA256SUMS for file hashes.
