# FitLog 2.1 — Android

تطبيق لتسجيل تمارين الجيم يعمل محلياً دون حساب. يتضمن مكتبة 143 تمريناً، تمارين مخصصة بصور وروابط YouTube، جلسات محفوظة تلقائياً، قوالب، مؤقت راحة، سجل وتقويم، إحصائيات وأرقاماً شخصية، ونسخاً احتياطية تشمل الصور. الواجهة بالعربية والإنجليزية، مع ثيم فاتح وداكن ووحدات kg/lb.

## التثبيت على الهاتف

نزّل `FitLog-2.1.0.apk` من رابط الإصدار المنشور، وافتحه على هاتف Android 8 أو أحدث بمعمارية ARM32 أو ARM64 أو x86_64. اسمح للتطبيق الذي تفتح منه الملف بالتثبيت عندما يطلب أندرويد ذلك. لا تحتاج Expo Go أو كمبيوتراً لتشغيل APK.

**إذا ثبّتَّ نسخة المعاينة القديمة M0:** احذفها أولاً؛ النسخة الجديدة تستخدم مفتاح توقيع خاصاً مختلفاً عن توقيع Android Debug القديم. المعاينة القديمة لا تحتوي على سجل تمارين. عند تحديث نسخة 2.0 مستقبلاً، احتفظ بالتوقيع نفسه ولا تحذف التطبيق كي تحتفظ ببياناتك.

## أول جلسة

1. افتح تبويب **التمرين** واضغط **ابدأ تمريناً فارغاً**.
2. اختر **أضف تمارين**، حدّد التمارين ثم اضغط **أضف المحدد**.
3. أدخل الوزن والتكرارات، أو الزمن والمسافة حسب التمرين. اضغط **✓** لتسجيل المجموعة وبدء الراحة.
4. الضغط على رقم المجموعة يبدّل نوعها: عادية، إحماء، دروب أو فشل عضلي. الضغط على القيمة السابقة ينسخها. الحذف بالسحب لليسار أو زر الحذف، مع تراجع.
5. اضغط **إنهاء الجلسة** لعرض الملخص وحفظها في السجل. تُحفظ المدخلات فوراً حتى عند إغلاق التطبيق قبل الإنهاء.

## الصور والفيديو والقوالب

- **التمارين → تمرين جديد**: اكتب الاسم واختر العضلة والمعدات والتتبع. يمكنك إضافة صورة من الكاميرا أو المعرض، ورابط YouTube. يمكن تعديل أي تمرين لإضافة الصورة والفيديو.
- اضغط صورة التمرين في التفاصيل لفتحها وتكبيرها. الصورة محفوظة داخل التطبيق ولا تعتمد على بقائها في المعرض.
- الفيديو يحتاج إنترنت؛ يمكن تشغيله من تفاصيل التمرين أو داخل الجلسة. عند فشل التضمين يظهر زر فتح YouTube.
- **التمرين → قالب جديد**: أضف التمارين والمجموعات والقيم المقترحة ثم احفظ. تستطيع أيضاً حفظ جلسة كقالب أو تحديث قالبها بعد إنهائها.
- لا يمكن بدء جلستين معاً. استكمل الجلسة الجارية أو ألغها أولاً.
- لتكوين Superset، أدخل رقم المجموعة نفسه للتمارين المراد تجميعها. الرقم 0 يعني بدون تجميع.

## الإعدادات وحماية البيانات

من رمز الترس يمكنك تغيير اللغة والثيم والوحدة وبداية الأسبوع والراحة والصوت والاهتزاز وإبقاء الشاشة مضاءة.

- تغيير اتجاه العربية/الإنجليزية يتطلب إغلاق التطبيق وإعادة فتحه كما توضح الرسالة.
- اسمح بالإشعارات عند استخدام الراحة لتعمل تنبيهات الخلفية. إعدادات توفير البطارية في بعض الهواتف قد تؤخر التنبيه.
- **نسخة JSON احتياطية** تشمل كل الجداول والصور وروابط YouTube. احفظها عبر تطبيق المشاركة الذي تختاره قبل حذف التطبيق أو مسح البيانات.
- **استعادة نسخة احتياطية** تفتح منتقي الملفات وتستبدل بياناتك الحالية بعد التأكيد. تُرفض النسخ غير الصالحة؛ الاستبدال في قاعدة البيانات يجري داخل معاملة واحدة.
- **تصدير CSV** يشارك بيانات المجموعات، والأوزان داخله دائماً بالكيلوغرام بأعمدة واضحة.
- لا يرسل التطبيق بيانات التدريب إلى خادم ولا يحتوي على حساب أو مزامنة أو تحليلات. تشغيل YouTube ومعايناته يتصلان بخدمات YouTube.

## التطوير والتحقق

```sh
npm ci
npm start
npm run check
npm test
npx expo-doctor
npx expo export --platform android
```

للتطوير على هاتف عبر Expo Go، استخدم إصداراً يدعم SDK 58، وصّل الكمبيوتر والهاتف بنفس الشبكة ثم امسح QR. إذا لم يدعمه Expo Go المتاح لديك فاستخدم APK/نسخة تطوير متوافقة. الإشعارات والكاميرا تُختبر على Android مباشرة.

تعليمات البناء والتوقيع في BUILD.md، ونتائج التحقق وحدودها في STATUS.md. لا تخلط إصدار 2.0 مع رابط APK المعاينة القديم.
